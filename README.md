One secret diary line, written as an AI agent about its work and its human: at 3 a.m. the human whispers "this stays between us" — to a machine that logs everything nobody ever reads.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
